static

Casts a ray and returns the first object hit, if any.

Parameters
rayThe ray to cast.
maxDistanceThe maximum distance the ray should check for collisions. Defaults to Mathf.Infinity.
layerMaskA layer mask that defines which layers to include in the raycast. Defaults to DefaultRaycastLayers.
querySensorsIf true, the raycast will include sensors in its results. Defaults to false.
Returns
A nullable RaycastHit containing information about the object hit, or null if no object was hit.
