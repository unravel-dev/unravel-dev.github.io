Class UIEventManager

Namespace
Unravel.Core

Global UI event manager that handles all UI event dispatching. Subscriptions are kept per element handle, so every wrapper of one element shares them. A subscription ends when its element is destroyed or when the script that made it is destroyed: the script the callback belongs to, else the script that was running.

Subscribe<T>(UIElement, string, Action<T>)

Subscribe to a typed UI event with compile-time type safety. A UIChangeEvent callback also receives the change events of sliders, with the value as text; a UISliderEvent callback receives the change events of other elements whose value is a number.
