Remarks

A coroutine is an iterator method that runs a step every frame until its next yield return. It can yield:

  • null - resume next frame;
  • WaitForSeconds, WaitForSecondsRealtime, WaitForFrames, WaitUntil, WaitWhile;
  • another IEnumerator - runs inline and returns here when it ends;
  • a Coroutine - waits until that coroutine finishes.

Coroutines run after every script's OnUpdate, follow the game clock (they pause with the game), and stop when their component is disabled or destroyed.
