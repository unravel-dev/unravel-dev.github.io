Class SpringBoneComponent

Namespace
Unravel.Core

Secondary motion for a chain of bones hanging from the bone it sits on (tails, ears, ponytails, cloth strips): every joint is a damped particle pulled back to its animated direction, pushed by gravity and kept out of colliders, simulated at a fixed rate.
