SampleHudController

Drives engine:/data/ui/sample_hud.rhtml through a data model: put it on an entity with a UI Document of that asset. The markup reads the HudState fields ({{ score }}, data-for over the inventory, data-value on the controls) and calls its public methods (data-event-click); the script only changes values and marks them dirty.

Sample script demonstrating the use of UI wrapper objects for caching and direct manipulation. This approach allows you to get UI elements once and keep them for later use without repeated searches. Also demonstrates the new typed UI event system with UIPointerEvent and UIKeyEvent.
