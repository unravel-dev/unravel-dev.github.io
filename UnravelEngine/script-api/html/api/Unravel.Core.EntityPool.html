Class EntityPool

Namespace
Unravel.Core

Reuses prefab instances via SetActive instead of Instantiate/Destroy each time. Suitable for high-churn gameplay objects (enemies, projectiles, pickups, VFX).

Remarks

For(Prefab) returns one shared pool per prefab. Scripts on an instance's root that implement IPoolable are told when the instance is acquired and released.
