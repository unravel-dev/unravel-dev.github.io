Remarks

A material with a non-empty uid refers to a shared material asset. A material with an empty uid is a standalone property block that can only be applied as a per-renderer override, for example through SetMaterial(Material, uint).

Remarks

The uid is deliberately not copied, so the result is a standalone property block. This is the idiomatic way to derive an editable material from a shared asset.
