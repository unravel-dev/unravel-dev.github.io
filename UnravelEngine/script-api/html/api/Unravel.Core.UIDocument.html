Class UIDocument

Namespace
Unravel.Core

Managed wrapper around a native RmlUi document (Rml::ElementDocument). Each UIDocumentComponent owns its own RmlUi context and document. Wrappers are cached by document, so repeated queries return the same instance. A wrapper is valid while its document is the component's open document: after Close() or a reload it reports IsValid() false and its calls do nothing.
