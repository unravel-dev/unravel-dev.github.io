Class UIStyle

Namespace
Unravel.Core

The inline style of an element (style). Values are RCSS text: el.style["opacity"] = "0.5"; setting null removes the inline value, so the stylesheet applies again. The numeric shortcuts write without formatting text, for per-frame changes.
