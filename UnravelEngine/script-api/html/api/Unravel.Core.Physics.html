Methods

Raycast(Ray, float, int, bool)

Casts a ray and returns the first object hit, if any.

public static RaycastHit? Raycast(Ray ray, float maxDistance = Infinity, int layerMask = -1, bool querySensors = false)

Parameters

ray Ray

The ray to cast.

maxDistance float

The maximum distance the ray should check for collisions. Defaults to Infinity.

layerMask int

A layer mask that defines which layers to include in the raycast. Defaults to DefaultRaycastLayers.

querySensors bool

If true, the raycast will include sensors in its results. Defaults to false.

Returns

RaycastHit?

A nullable RaycastHit containing information about the object hit, or null if no object was hit.
