Class UIElement

Namespace
Unravel.Core

Managed wrapper around a native RmlUi element (Rml::Element). Obtain instances via GetElementById(string) / QuerySelector(string); each element has one wrapper. A wrapper outliving its element (after an InnerRml rebuild of an ancestor, or a document close or reload) is safe: it reports IsValid() false, its setters do nothing and its getters return defaults. Fetch the element again from the document.

Animate(string, string, float, UIEasing, int, bool, float)

Animates a property from its current value to @p target. Another animation of the same property is replaced. RCSS keyframes and transitions remain the way to author designed motion; this is for motion decided in code.

public UIAnimation Animate(string property, string target, float duration, UIEasing easing = UIEasing.Linear, int loops = 1, bool alternate = false, float delay = 0)

Parameters

property string

An animatable RCSS property, e.g. "opacity", "left", "transform", "color".

target string

The end value as RCSS text, e.g. "0", "120dp", "rotate(90deg)", "#ff0000".

duration float

Seconds per run.

easing UIEasing

The curve.

loops int

How many runs; -1 runs forever.

alternate bool

Every other run goes backwards.

delay float

Seconds before the first run.

Returns

UIAnimation

The animation; check isRunning - false when the property or value is invalid.

Examples

panel.Animate("opacity", "0", 0.3f, UIEasing.CubicOut).completed += () => panel.visible = false;
coin.Animate("transform", "scale(1.4)", 0.15f, UIEasing.BackOut, loops: 2, alternate: true);
