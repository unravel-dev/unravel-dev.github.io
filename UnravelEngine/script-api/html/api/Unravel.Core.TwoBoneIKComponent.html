Class TwoBoneIKComponent

Namespace
Unravel.Core

Analytical two-bone IK on the bone it sits on (a hand or a foot): the bone reaches its target, bending its parent (elbow, knee) toward the pole. Runs after scripts, before skinning, on top of the animated pose, and leaves the animated pose untouched.
