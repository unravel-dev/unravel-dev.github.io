SetSharedMaterial(Material, uint)

Sets the shared material asset at the specified index for the model.

public void SetSharedMaterial(Material material, uint index = 0)

Parameters

material Material

The Material to assign, or null to remove the material.

index uint

The index of the material to set.

Remarks

Only asset-backed materials can occupy a shared slot. A material with an empty uid, such as one returned by GetMaterial(uint) or built with Material(Material), is applied as this renderer's material instance instead of clearing the slot.
