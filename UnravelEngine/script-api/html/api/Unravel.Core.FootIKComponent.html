Class FootIKComponent

Namespace
Unravel.Core

Plants a character feet on uneven ground: probes the ground under each foot, lowers the pelvis to the lowest planted foot, solves each leg with two-bone IK and tilts the feet onto the slope. Sits on the character root; the probes need physics, so it acts in play mode.
