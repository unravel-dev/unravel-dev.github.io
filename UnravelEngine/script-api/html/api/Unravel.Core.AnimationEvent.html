Struct AnimationEvent

Namespace
Unravel.Core

A marker on an animation clip's timeline that playback crossed this frame.

Events are authored per clip (clip inspector, Events tab) and delivered to the scripts on the entity that has the AnimationComponent - or, when that entity has no scripts, on its nearest ancestor with scripts. Every script receives OnAnimationEvent(AnimationEvent), and a public method named exactly like the event is called as well, taking nothing, an AnimationEvent, or the event's string, float or int parameter.
