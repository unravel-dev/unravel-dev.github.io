AutoStaticsCleanupAttribute

Marks a class whose static state must be reset when a script domain is unloaded (CoreCLR backend).

On Mono, unloading a domain destroys its statics wholesale. On CoreCLR a collectible AssemblyLoadContext only unloads once nothing references it anymore, so static caches in a surviving assembly (e.g. managers holding script instances or script Type objects) would silently keep the unloaded domain alive. The runtime processes this attribute right before any domain is unloaded:

  • If the class defines static void OnStaticsCleanup() (any visibility), that method is invoked and nothing else happens - use it to re-create managers or clear collections selectively.
  • Otherwise every non-readonly static field is reset to its default value. Readonly statics cannot be cleared by reflection and produce a warning - define OnStaticsCleanup for those.

The attribute is matched by name, so any assembly may use it without referencing the engine. On Mono it is ignored.

IK

Inverse-kinematics helpers for skeletal chains.

Call these from OnUpdate. Scripts run after the animation system has evaluated the pose and before skinning, so bone writes made there are what gets rendered. Writing bones from OnFixedUpdate does not work - animation will overwrite them later in the frame.

Every method returns true when a pose was written. A false means the chain was too short, the goal was not finite, or the weight was zero - not that the target was out of reach (an unreachable target still produces a valid stretched pose).

The position solvers only orient the bones that drive the chain, never the end effector itself, so a solved foot keeps the orientation animation gave it. Follow a position solve with SetIKRotation(Entity, Quaternion, float) to pin a foot to a slope or keep an aimed hand level.

Poles must come from a reference the solve does not move - the character root, or a dedicated hint entity. A pole derived from the end effector's own transform closes a feedback loop: the solve rotates the effector, the pole follows it, the chain chases the pole, and the limb spins.

ScriptComponentManager

Optimized manager for ScriptComponents with type-based priority.

  • Per-type buckets: Components of same type never sorted against each other
  • Slot reuse: Removed components leave gaps that are reused (no shifting)
  • O(1) removal: Dictionary lookup instead of linear search
  • Minimal allocations: Reuses collections across frames
  • Deferred operations during invocation for thread safety
  • Method override detection: Only adds components that actually override Update/FixedUpdate/LateUpdate

AnimationEvent

A marker on an animation clip's timeline that playback crossed this frame.

Events are authored per clip (clip inspector, Events tab) and delivered to the scripts on the entity that has the AnimationComponent - or, when that entity has no scripts, on its nearest ancestor with scripts.
