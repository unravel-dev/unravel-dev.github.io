Class LookAtIKComponent

Namespace
Unravel.Core

Turns a chain of bones (head, neck, chest) toward a target, the lower bones taking a smaller share and the tip finishing the aim, each limited to a cone around its animated facing. Smoothed, and faded out when the target goes behind the character.
