FindChild(string, bool)

Finds a child by name/path and returns it. If no child with name n can be found, null is returned. If n contains a '/' character it will access the Transform in the hierarchy like a path name Note: Find does not work properly if you have '/' in the name of an Entity. Note: Find can find transform of an inactive/disabled Entity

public Entity FindChild(string path, bool recursive = false)
