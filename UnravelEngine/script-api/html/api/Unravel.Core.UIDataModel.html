Class UIDataModel

Namespace
Unravel.Core

A data model of a UI document: the values and events its markup binds to. The document declares it with data-model="name" on an element; inside that element {{ credit }}, data-if, data-for, data-class-, data-style-, data-attr-, data-value, data-checked and data-event- read the model.

Examples

// <body data-model="hud"> {{ credit | money }} <button data-event-click="Spin()">
var model = ui.GetModel("hud");
model.Bind(hud);                                  // HudModel's public fields, properties, methods
model.AddTransform<long>("money", v => $"{v:N0}");
hud.credit += win;
model.Dirty(nameof(HudModel.credit));

Remarks

Get it with GetModel(string); it exists before and across document (re)loads. Changes are pushed: after changing a bound value call Dirty(string) (or DirtyAll()); views using it update at the next frame. Controls bound with data-value / data-checked write back and update by themselves. Values: bool, integers and floating point numbers, string, enums (as their name), Color (as an RCSS colour); classes and structs become nested variables ({{ row.name }}), lists and arrays become arrays (data-for="row : rows", rows.size). Bindings end with the script that made them.

AddTransform(string, Func<object, object[], object>)

Adds a transform for {{ value | name }} or {{ value | name(arg) }}. It serves every model of the document. Integers arrive as long and numbers as double; use AddTransform<T>(string, Func<T, object>) to receive a converted value.

Bind(object)

Binds an object: its public fields and properties become variables (writable ones accept data-value writes), its public methods become events (data-event-click="Spin()"; a first parameter of an event class receives the event, the others the expression's arguments; the model is marked dirty after it runs). Binding another object replaces this one; names it lacks become empty.

public void Bind(object source)

Parameters

source object

The object; it is read at every update of a view that uses it.
