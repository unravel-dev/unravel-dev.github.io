Size of the view the game is shown in: the window in the player, the Game panel's resolution in the editor. Same pixel space as mousePosition.

Remarks

Set before the scripts update, to the size the frame renders at; in the player also before play begins. In the editor a free-aspect resolution is known once the Game panel has been shown (zero before), and the size keeps its last value while the panel is hidden. A single camera's size is viewportSize.
