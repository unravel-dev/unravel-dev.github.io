◆ generate_sdf()

auto unravel::mesh::generate_sdf ( const mesh_sdf_bake_settings & settings = runtime_sdf_bake_settings()) -> bool

Bakes a signed distance field for this mesh from its prepared geometry.

For meshes built at runtime. Compiled assets carry a field baked by the asset compiler, which is preferable because it happens once at import rather than on every load; a mesh created procedurally has no such opportunity, and without a field it is invisible to the surface cache – it neither occludes nor bounces indirect light.

Must be called after end_prepare, which is what populates the system-memory vertex and index buffers this reads.

Parameters
settingsBake controls. The default resolution is deliberately lower than the asset compiler's, since this runs synchronously on load and primitives are simple shapes that a coarse field represents well.
Returns
true when a usable field was produced.
