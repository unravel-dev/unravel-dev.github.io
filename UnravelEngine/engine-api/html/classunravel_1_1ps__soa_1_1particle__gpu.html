Detailed Description

The GPU side of the particles: one pool of particle records shared by every emitter, the emitter tables, the curve-set atlas, and the per-view cull / sort / draw work.

Everything the CPU writes goes through bgfx updates of CPU-written buffers (tables, curve atlas, staging) at flush; the record pool is GPU-written, filled by the scatter kernel from the staging buffer. bgfx applies a frame's updates before any of its views run, so each flush within a frame stages into its own buffer.
