Detailed Description

An edit-mode preview that animates a scene entity and puts it back as it found it.

The preview ends by itself when the tool showing it stops calling keep_alive() (its window was closed or hidden) and when the project closes. Everything that writes a scene out - scene and prefab saves, the checkpoints of play start and script recompile, and the entity snapshots of duplicates and undoable deletes - calls stop_all() first, so a preview never leaks a pose into the play scene, a saved scene or a copy. An entity has one preview at a time: starting another one on it stops the first, so the pose that comes back is the entity's own.
