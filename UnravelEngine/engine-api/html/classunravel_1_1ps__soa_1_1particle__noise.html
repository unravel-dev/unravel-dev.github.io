Detailed Description

A tileable, divergence-free vector field (the curl of a smooth random potential) with lengths up to 1, which turbulence displaces particles by. The GPU samples the same values from a 3D texture (particle_vertex.sh, s_particle_noise); the CPU mirror samples them here.
