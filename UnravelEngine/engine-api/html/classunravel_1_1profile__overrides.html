Detailed Description

What a profile overrides in one settings document: the overridden properties and their values, kept as a sparse document that states only those and is loaded over a copy of the base.

The overridden paths are the document's leaf paths (serialization::get_leaf_paths): objects are walked into, while a value, an array or an asset handle is overridden as a whole. Properties the base does not override stay the base's, so a later edit of the base reaches every profile that leaves it alone.
