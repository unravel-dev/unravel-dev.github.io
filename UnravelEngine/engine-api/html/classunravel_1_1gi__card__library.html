Detailed Description

Surface cache card sets per (mesh asset, submesh, two-sidedness).

A card set depends on the submesh's triangles and on whether its material is two-sided, never on a placement, so every placement of a submesh shares one set. An imported mesh carries its sets from the compiler (one per submesh, for the material it imported with); the library builds a set on the thread pool only for a mesh without them (procedurally created) or for a placement whose material flips the sidedness.

The submesh's cards, or null while they are being built.

The mesh's compiled set when its sidedness matches (an empty set when the import settings turned cards off). Otherwise the first request schedules a build; later requests return null until it finishes, then the shared set. A submesh whose geometry has no triangles gets an empty set, not a retry.
