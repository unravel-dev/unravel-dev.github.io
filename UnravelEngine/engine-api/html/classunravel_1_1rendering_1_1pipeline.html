virtual

Draws the particles over the lit scene.

Parameters
hiz_depthThis frame's Hi-Z buffer when the pipeline built one: soft particles read its first mip. Without it they read a copy of the depth buffer made for them.
use_shadow_mapsThe run built this camera's shadow maps: lit particles may read the sun's.
wants_reactiveThe view's TAA runs and reads the particles' reactive coverage; without it the particles write only the light buffer.
dtThe frame's time step: the camera's velocity over it stretches the particles that stretch against it.
Returns
The particles' TAA reactive coverage (R8: the largest coverage x taa_response over each pixel) when particles drew into it this frame; null otherwise.
