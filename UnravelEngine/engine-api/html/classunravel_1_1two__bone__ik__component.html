Detailed Description

Analytical two-bone IK on the bone it sits on (a hand or a foot): the bone reaches its target, bending its parent (elbow, knee) toward the pole.

Rig modifiers run every frame after scripts, before skinning, on top of the animated pose, and leave no trace: the input pose comes back before the next frame animates (in edit mode right after skinning), so a modifier never accumulates and can be previewed in edit mode.
