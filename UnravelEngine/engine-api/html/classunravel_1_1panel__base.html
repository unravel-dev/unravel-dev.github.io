void unravel::panel_base::hold_visible_force ( uint32_t frames)
inline

Keeps the panel's view rendering for the next frames frames even while its tab is hidden, so a view that builds on earlier frames (temporal AA, GI) is not torn down between two requests. Extends a shorter hold, never shortens one.
