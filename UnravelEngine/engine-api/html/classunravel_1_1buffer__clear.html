Detailed Description

Zeroes a range of a uint buffer the GPU writes (cs_clear_uints.sc). bgfx updates no BGFX_BUFFER_COMPUTE_WRITE buffer from the CPU (its debug checks fail every such update, and the D3D11 backend did not create the buffer dynamic), so a frame's counters in one start over by a dispatch ordered before their first reader: earlier in the same view (bgfx runs a view's dispatches in submission order) or in an earlier view.

Users: the GI gather's probe trace ray count (gi_gather_pass) and shader_print's header (the symbol count).
