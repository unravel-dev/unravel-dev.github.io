Detailed Description

template<typename T>
class math::curve< T >

A value of type T keyed over a range, one independently keyed channel per component.

Channels are linked by default, meaning every channel carries a key at the same positions. That is what a gradient is, and it is what the key-list half of this interface reads and writes. Unlinking lets one channel be keyed on its own - separate alpha keys on a color, a size range whose two ends move differently.

Sampling is direct unless bake has been called, which trades memory for a table lookup.

◆ bake()

template<typename T >
void math::curve< T >::bake ( size_t resolution = 256)

Pre-samples the curve so later sampling is a table lookup.

The table spans the curve's own domain, and is read without interpolating when any channel steps, so baking never changes what the curve means. Any edit drops the table; call this again once the curve settles.
