std::function<void(camera&, const usize32_t& viewport_size)> unravel::rendering::pipeline::run_params::apply_taa_params

When set with fill_taa_params, applies jitter / temporal AA state to the camera (typically camera::set_aa_data). When TAA is off, leave empty; the deferred path resets AA on the camera.
