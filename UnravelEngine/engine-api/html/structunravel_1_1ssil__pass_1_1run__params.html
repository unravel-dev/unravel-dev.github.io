gfx::texture::ptr unravel::ssil_pass::run_params::irradiance_sh

Environment SH coefficients (9x3 R32F); sampled per ray as the miss fallback so the trace integrates the environment where it escapes on-screen geometry. May be null on the first frame, in which case the fallback is disabled (misses = 0).
