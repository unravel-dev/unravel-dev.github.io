◆ readTexture()

bool readTexture ( bgfx::ViewId viewId,
bgfx::TextureHandle _texture,
uint32_t width,
uint32_t height,
ReadbackFn _onLanded )

Reads mip 0 of _texture (non-MSAA RGBA8, width x height) back to the CPU. The pixels come back through a GPU readback that lands a couple of frames later, so this only issues the copy in viewId (which must run after the texture is final); gfx::frame() hands them to _onLanded once they are there. Returns false when the copy could not be issued.

Saves the first color attachment of fbo (non-MSAA RGBA8, width x height) as a PNG at _filePath through readTexture: gfx::frame() writes the file once the readback has landed. Returns false when the copy could not be issued. Window framebuffers have no attachment; use bgfx::requestScreenShot for those.
