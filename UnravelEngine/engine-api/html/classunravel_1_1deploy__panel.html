Detailed Description

The Deploy Project window: tabs for what the game is and where it goes (Build), what it ships (Content) and the releases it patches (Releases); under them, always in view, what still keeps it from deploying, the steps of the deploy while it runs, and the buttons.

It deploys one settings profile at a time, the deploy profile, chosen in the Build tab. The settings every profile shares are edited for all of them, or as overrides of the deploy profile.
