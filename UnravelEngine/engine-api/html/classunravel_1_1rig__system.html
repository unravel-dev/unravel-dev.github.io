Detailed Description

Runs the rig modifiers (IK and spring bone components) on top of the animated pose.

Order per frame and scene: the animation system writes the pose, scripts run (they may move IK targets), then before_skinning() saves the local transform of every entity a modifier may write and runs the modifiers parents first: a modifier runs after every modifier whose joints are higher in the hierarchy, so a look-at that turns the chest runs before the hand IK on the arm it moves. Skinning reads the result, and after_skinning() hands the input pose back, so the modifiers never accumulate and never dirty a scene.

In the scene being played the solved pose is held through the render: what hangs under a solved bone (a weapon in the hand, a head camera) and rigs drawn from their transforms show it. The input pose comes back at the start of the next frame (restore_deferred()), unless something moved the entity in between. Everywhere else (edit mode, prefab and thumbnail scenes) it comes back right after skinning, so editing and saving never see a solved pose: skinned meshes show the solve, attachments and plain entity rigs show it in their gizmos.

The state of a scene lives in its registry's context and goes away with it.
