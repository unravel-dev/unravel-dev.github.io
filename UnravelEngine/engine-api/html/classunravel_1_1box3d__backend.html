Detailed Description

Box3D implementation of physics_backend.

Rigid bodies map to one Box3D body with one runtime shape per compound entry; the entity scale is baked into the shapes. The character controller is a geometric capsule mover (cast / collide / solve planes) backed by a kinematic proxy body so sensors and dynamic bodies still see it. Contact bookkeeping reuses contact_graph and folds the current touching set every step, so the enter / exit semantics match bullet_backend.
