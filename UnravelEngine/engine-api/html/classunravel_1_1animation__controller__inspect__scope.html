Detailed Description

The controller the Animation Controller window inspects the definitions of.

While one is open, the inspectors below draw a state, transition, parameter or layer of it like any reflected type - the generic rows, groups, tooltips and visibility rules - and the fields that need the controller their own way: names (a rename keeps every reference), parameter and state pickers, conditions by their parameter's type, the blend plot and the mask's bones. Without one they draw like the generic inspector.
