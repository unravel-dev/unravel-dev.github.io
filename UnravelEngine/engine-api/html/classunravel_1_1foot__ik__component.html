Detailed Description

Plants a character's feet on uneven ground: probes the ground under each foot, lowers the pelvis to the lowest planted foot, solves each leg with two-bone IK and tilts the feet onto the slope. Feet lifted by the animation (swing) and ground far below a foot fade the IK out.

Sits on the character's root (feet level). Probes need the physics world, so it runs in play mode.
