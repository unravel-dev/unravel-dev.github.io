Detailed Description

The Animation Controller editor: a graph of every layer's states and transitions, the controller's parameters and layers, an inspector for the selection, live debugging of the entity using the controller and an edit-mode preview.

The selection is inspected with the inspector itself (inspect(), with the controller types' inspectors in animation_controller_inspectors.h), so it reads like any other inspector. Every finished edit saves the controller and can be undone with Ctrl+Z while the window has focus; the scene's own undo, redo and save shortcuts stay out of it meanwhile.
