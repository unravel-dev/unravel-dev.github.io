◆ invoke_on_main()

template<typename Fn >
auto unravel::mcp_manager::invoke_on_main ( Fn && fn,
std::chrono::milliseconds timeout = std::chrono::milliseconds(5000),
std::string * failure = nullptr ) -> hpp::optional<std::invoke_result_t<std::decay_t<Fn>>>
inline

Runs fn on the editor main thread and waits for it. Safe from MCP HTTP workers.

fn runs from the main thread's task processing at the frame start (tpp::async_on_process), never from a wait in the middle of a frame. A call either runs or does not: when timeout passes before the main thread picks fn up, fn is abandoned and never runs; once it has started, the caller waits for it to finish however long it takes. So fn may capture the caller's locals by reference, and a timeout always means "nothing happened".

Parameters
failureWhen set, receives why the result is empty: the timeout or the exception text.
Returns
fn's result, or nullopt when it timed out before starting or threw.
