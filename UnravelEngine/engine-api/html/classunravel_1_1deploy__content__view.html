Detailed Description

The Deploy window's Content tab: the scenes the game is built from, and every project asset in a folder tree with whether it ships and why.

The content comes from deployment::detect_content, run off the main thread whenever what it was detected from (the project, the startup scene, the scene list) changes, when the window opens and on Detect. A checkbox sets an include or exclude rule on its folder or asset; the tree model recounts only when the rules or the view change, and only the visible rows are drawn.
