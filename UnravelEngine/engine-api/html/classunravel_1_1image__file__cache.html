Detailed Description

Images read from files on disk for the pages the editor draws itself: the thumbnails of projects and samples, the logo of the loading screen.

A file is read once, and again only when refresh() finds it changed on disk. Each image gets a mip chain, so it stays smooth however small it is drawn. Few files are read per frame, so a page full of them comes up without a stall: an image not read yet is null for a frame or two.
