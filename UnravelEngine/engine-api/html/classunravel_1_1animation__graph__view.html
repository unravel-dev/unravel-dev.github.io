Detailed Description

Pan / zoom canvas drawing one layer's state machine: states, Entry, Any State and the transitions between them, with move, link, create, delete and context menus.

Edits are made directly on the layer definition; draw() reports them so the owner can snapshot for undo before the first change of an interaction and save once it finishes.
