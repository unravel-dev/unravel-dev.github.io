Detailed Description

Snapshots the scene-referred HDR target into PREV_SCENE_HDR for next frame's feedback readers (the GI gather's screen tier and far field, SSR), with each pixel's view depth in alpha so a reader can validate its reprojection against the surface the pixel was rendered from (fs_gi_scene_snapshot.sc).

Replaces a plain blit: same cost (one full-screen pass over the same target), one more channel of meaning.
