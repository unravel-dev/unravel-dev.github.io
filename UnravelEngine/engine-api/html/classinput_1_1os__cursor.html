Detailed Description

The OS cursor as the game asks for it: held at the center of the work zone (locked) or inside it (confined), shown or hidden.

A request applies only while the game has input: input is allowed, one of the application's windows has focus, the host has not suspended it and no virtual pointer stands in for the mouse. So a held cursor never keeps the user from the editor or another application. The input manager reports those conditions as they change and calls apply() once per frame, after it read the frame's motion.
