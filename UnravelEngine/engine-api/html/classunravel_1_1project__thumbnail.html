Detailed Description

The picture of a project on the start page and on the screen that opens it.

A project can carry a picture of its own, thumbnail.png in its folder, kept and shared with the project. Without one, the editor shows the view it captured into the cache of the project: once a while after a project without any thumbnail opens, and again whenever a scene is saved. The view is what the game camera sees, rendered for a few frames first so that it has settled, or the Scene view when the scene has no camera.
