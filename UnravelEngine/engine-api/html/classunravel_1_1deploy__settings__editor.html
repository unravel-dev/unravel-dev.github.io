Detailed Description

The deploy settings the Deploy window shows and edits: the ones every profile shares, or the deploy profile's, where an edit becomes an override of that profile.

Call sync at the start of every frame the window draws: it takes the project's current settings and deploy profile unless an item is being edited. After an edit is finished, commit writes what the edit changed where edits go, over the settings as they are then.
