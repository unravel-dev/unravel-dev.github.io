Detailed Description

Runtime of one animation_controller on one entity: parameter values, the active state and transition of every layer, and the player calls that realise them.

Per frame the animation system calls update() BEFORE advancing the player: it starts the default states, lets curves drive same-named float parameters, fires the transitions whose conditions and exit times hold, and pushes blend parameters and speeds into the player.
