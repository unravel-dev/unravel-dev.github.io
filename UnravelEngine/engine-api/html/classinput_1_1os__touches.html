Detailed Description

The fingers on the touch screen, frame by frame.

A finger begins in the frame it touches, is moved or stationary in each frame it stays, and is ended (or canceled) for one frame after it leaves. A finger that touches and leaves within one frame still reads as began first: its end shows in the next frame. The input manager calls update() at the start of each frame, before it hands over the frame's finger events.
