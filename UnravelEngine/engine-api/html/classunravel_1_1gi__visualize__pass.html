Detailed Description

The GI debug views, drawn over the finished image: the scene views the surface cache traces (gi_surface_cache_pass::run_debug, the card atlas, coverage and object grid views among them), the screen-space views (fs_gi_visualize_screen.sc: Dedicated Reflection Rays, Screen Probe Frames Accumulated), and two overviews, which tile views over the lit image and name each tile.
