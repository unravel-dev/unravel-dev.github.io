◆ prefab_role

enum class unravel::entity_panel::prefab_role
strong

Where an entity in a prefab instance came from.

The hierarchy showed everything with any prefab component in one colour, so a nested instance the prefab supplies and one added here looked identical - and so did an entity of the asset and an entity added inside it.

Enumerator
none 

Nothing to do with a prefab.

instance 

A prefab instance placed directly in whatever it lives in, rather than nested inside another instance. The ordinary case, and nothing to call out.

linked_instance 

A prefab instance the prefab containing it supplies. Its instance id names which.

local_instance 

A prefab instance added or cloned inside another instance. No instance id, and no document above it will ever remove or replace it.

asset_content 

An entity the instance's own asset supplies.

local_content 

An entity added inside an instance. Its asset knows nothing about it.
