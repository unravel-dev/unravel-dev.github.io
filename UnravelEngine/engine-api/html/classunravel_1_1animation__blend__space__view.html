Detailed Description

Plot of a blend state's points: a track for 1D blends, a plane for 2D ones.

Points drag to new positions. When the state is playing live, every point shows its current weight and the input parameters show as a marker; dragging on empty space moves that marker, which the owner writes back into the running controller as a preview. The axes fit the points and the marker, and hold still while something is dragged so it does not run away.
