Inspects a mono_object that directly represents a value of type T.

This method is used when the mono_object itself is a value type (e.g., a boxed int32_t or math::vec2) and should be inspected directly without going through fields/properties.

Parameters
ctxThe RTTI context
objThe mono_object to inspect (must be a value type representing T)
obj_proxyThe proxy for the object
infoVariable info
Returns
inspect_result The inspection result
