◆ apply_game_view_size()

void unravel::rendering_system::apply_game_view_size ( scene & scn,
const usize32_t & size )

Sets the size of the view the game is shown in and sizes every camera of scn to it.

The host calls it in the frame update ahead of the scripts, so a frame's scripts read the size that frame renders at.

Parameters
scnThe scene whose cameras show the game.
sizeThe size in pixels.

◆ set_game_view_size()

void unravel::rendering_system::set_game_view_size ( const usize32_t & size)

Sets the size of the view the game is shown in: the main window in the player, the Game panel's resolution in the editor.

The host showing the game sets it whenever it sizes the game cameras; scripts read it as the screen size.

Parameters
sizeThe size in pixels.
