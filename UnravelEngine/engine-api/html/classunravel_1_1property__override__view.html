Detailed Description

Marks the properties a settings profile overrides while an object is inspected, says so in their tooltips, and offers reverting one from the property's context menu.

Active only inside a property_override_scope. The inspector pushes each property's name as it draws it, so the view knows the path of the property being drawn ("graphics/particles/spawn_scale", from the root the scope names): the serialization path the profile's overrides use. Each property gets its own mark: a group holding overrides does not mark the properties in it that are not overridden.
